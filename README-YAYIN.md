Kurulum:
1. ZIP'i açın.
2. `_posts` klasöründeki dosyaları repodaki `_posts` klasörüne kopyalayın.
3. `assets/img` dosyalarını repodaki aynı klasöre kopyalayın.
4. Commit + push yapın.
5. GitHub Pages deploy'unu kontrol edin.

Not: “iPhone 27” ifadesi kullanılmadı. 2026 itibarıyla doğru güncel başlıklar Xcode 27, iOS 27 ve iPhone 18/katlanabilir iPhone söylentileridir.
